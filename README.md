## Sobre o projeto

Site estático feito com **HTML, CSS e JavaScript puro**: sem frameworks, sem dependências e sem etapa de build. Basta abrir o `index.html`.

A identidade visual segue o logo do dojo: **preto**, **branco** e o **vermelho do sol**.

## Seções do site

| Seção          | Conteúdo                                                                 |
| -------------- | ------------------------------------------------------------------------ |
| **Início**     | Apresentação, com o logo e o sol vermelho                                |
| **Filiações**  | SKAA e CBKJ                                                              |
| **O Dojo**     | História e pilares da academia                                           |
| **Dojo Kun**   | Os cinco preceitos do Shotokan                                           |
| **Horários**   | Grade de treinos                                                         |
| **Graduação**  | Sequência de faixas, da branca à preta                                   |
| **Contato**    | Formulário que abre uma conversa no WhatsApp com a mensagem preenchida   |

## Estrutura de pastas

```text
shurikan-karate/
├── index.html          # Página única com todas as seções
├── css/
│   └── style.css       # Estilos e variáveis de cor
├── js/
│   ├── config.js       # WhatsApp, Instagram e endereço
│   └── main.js         # Menu, animações e formulário de contato
└── assets/
    └── img/
        └── logo.png
```
